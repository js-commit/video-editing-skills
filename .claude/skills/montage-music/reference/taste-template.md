# What to remember about the user's music taste

Taste is personal, so it lives in `user/preferences.md` under `## montage-music`, never in this
skill. Ask a couple of these the first time (not all of them), and add a bullet whenever the user
reacts to a sample or a draft ("too sad", "love this one", "no vocals"). Write the reason too:
"rejected X: too cheesy for a memorial" helps more than "rejected X".

```
## montage-music
- Default mood for family videos: <e.g. upbeat and warm / calm and nostalgic>.
- Vocals: <instrumental only / vocals fine / vocals only when I name the song>.
- Likes: <instruments, genres, eras>, e.g. piano, synth-pop, brass band, lo-fi beats.
- Dislikes: <what to avoid and why>, e.g. heavy drops, overly dramatic film scores.
- Liked tracks (reuse when the mood fits): <file names>.
- Rejected tracks and why: <file name> - <reason>.
- Where my music lives: <folder>; library I download from: <name>.
- Published videos: YouTube Audio Library only / CC with credit / my own music.
- Loudness: <the clips' own sound clearly audible / music up front>.
```

Things worth asking about only when relevant: a culture or place the music should nod to (a trip
abroad), a song that means something to the family (a memorial), whether a joke moment deserves a
sound effect or a musical sting.
