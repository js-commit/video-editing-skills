Questions

Fair questions.

What do I need?

Claude Code with a Claude plan (Pro or Max) and a Mac works best. Setup checks the rest, offers to install ffmpeg, and helps you pick how speech becomes text (ElevenLabs Scribe has a free tier; on newer Macs, voz is free and offline). DaVinci Resolve is optional.

Is it free?

Yes, it's open source (MIT). Claude Code uses your Claude plan, and a long recording uses a fair bit of it.

Do I need editing software?

No. It can do the whole edit on its own. If you use DaVinci Resolve, it can build the timeline there for you to fine-tune.

Will it make my video sound like AI?

No. The first cut only cuts your own words: the mistakes go, everything you meant to say stays, jokes included.

Windows or Linux?

The Mac gets the most testing and the ready-made apps. The core editing is written to work on Windows and Linux too.
